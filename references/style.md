# Personal academic diagram style

Derived from the author's supplied `overview.graffle`, `rl_mutation.graffle`, and `skillbank.graffle` examples. The originals are project inputs, not bundled assets.

| Element | Default | Application |
|---|---|---|
| Text | Times New Roman | PostScript names `TimesNewRomanPSMT`, `TimesNewRomanPS-BoldMT` |
| Code | A legible installed monospace font | Only when code is essential to the explanation |
| Light blue | `#DBF3FF` | Processing, state or checking panels |
| Stronger light blue | `#C9ECFF` | Section strips, adapted from mutation figures |
| Light yellow | `#FFF3C9` | Review, criteria or knowledge panels |
| Light pink | `#F9DFF6` | Inputs or a separate logical phase |
| Light gray | `#EFF3F8` | Secondary, neutral or unknown state |
| Text ink | `#333333` | High contrast against pastel backgrounds |
| Connectors | `#6B7C91` | Thin, readable arrowed lines |
| Corners | About 2 pt at final size | Slight rounding; no decorative shadow |

These are reusable style tokens, not mandatory semantic color assignments. Each figure's legend defines its actual meaning. The demonstrated 474 × 234 pt two-column diagram used 10pt bold labels, 9.5pt descriptions and 0.65pt strokes. Those dimensions are an example, not a venue requirement; derive each new size from the manuscript.

Prefer aligned panels, short labels, explicit arrow direction and clean feedback paths. Use full pastel panels for compact nodes or colored heading strips for dense method explanations. Do not reproduce decorative icons when they add no meaning. Preserve grayscale readability through text and line styles.
